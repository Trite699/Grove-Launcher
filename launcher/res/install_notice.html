Welcome to Mystical Grove

Mystical Grove is a Attorney Online server made by Rhamnous which allows people to participate in different kinds of activities such as casing, role-playing, werewolf and much more!

Please be sure to follow the server rules, and, if applicable, join the discord server, which may be found in server's description.

You will be downloading the Grove - 2026 base This will add a LOT of content, including any and all files required to access Mystical Grove's content, be warned! It will make MAJOR changes, and even include a favourites list, please do not panic! If disk space is a concern, we invite you to use webAO to join the server.
